# 插件书架 0.5.0 验证记录

本轮完成用户确认的六项优化，仅修改 dsh-plugin-shelf，不修改 DSH 本体或插件市场。设置仍只在插件详情页；「更多 → 书架设置」跳转到同一详情。

## 改动

- 安装信息改变或原生刷新时清除旧更新结果；安装信息按宿主 DOM 变化重新读取，检测请求取消后迟到结果不覆盖新状态。
- 更新数量区分未检查、检查中、待重新检查、已检查且无更新；筛选失效时返回全部，避免空列表。
- 工具栏收为两行；合并全部折叠／展开，更多菜单包含刷新安装信息、清除筛选和书架设置，支持 Esc 与点击外部关闭。
- 置顶管理提供上移／下移，常用入口与卡片共享顺序；取消置顶在 8 秒内可撤销且恢复原位置。
- Tab／Shift+Tab 跟随视觉顺序，跳过隐藏及折叠内容并允许离开页面；保留宿主 React 节点，不搬动原生卡片。
- 将列表增强开关与原生插件启停区分，统一图钉文案，保存失败时不显示已保存。

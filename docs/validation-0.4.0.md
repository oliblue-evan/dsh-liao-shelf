## 重要语义

安装时间取当前 Profile 条目的 lstat.birthtime，链接不会取源码仓库的创建时间。不声称历史首次安装时间，展示中明确标为估算；更新、重装或恢复可能改变它。缺失条目返回 unknown，不填当前时间。未知日期排在已知日期之后，置顶保持优先。

搜索／筛选临时展开分组，清除后恢复存储的折叠状态。极简布局隐藏描述、状态、时间和额外标签，仅留下图标、名称、图钉和原生开关。验证旧到新排序时，2026/10/12 的模型整理器、2026/10/13 的 GitHub 授权排在 2026/10/14 项目前。

检查更新仅点击时触发，无轮询、无 POST 升级、无包管理器进程。市场负责 npm/Git/本地链接与升级方向的判断。汇总分母保留市场给出的 checked（可能包含 Profile 依赖），不替换成书架卡片数量。Git 目标显示短提交 ID，完整值放在提示中。错误、未知协议、市场缺失与 checked=0 均不宣称全部最新，失败清除旧结果。

测试使用宿主 DOM fixture 与测试 Context；真实加载器、真实 HTTP 服务测试和本机 GUI 补充证据，不将 fixture 当作完整宿主冷启动。请求超时、停用取消和路由生命周期已覆盖。

测试收藏已撤回。显示恢复为验证前用户正在使用的极简视图、原始排序与展开状态。

## 回退

只恢复上方备份中本插件的文件，保留其他仓库与 DSH 本体；不要使用 git reset --hard，否则会丢失本轮之前的 0.3.0 未提交改动。回退后重新载入进程，使新增只读路由撤回。不要清除本地收藏或配置。临时打包文件由检查脚本自动删除；备份保留供回退。

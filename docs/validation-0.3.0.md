## 回退

```sh
git restore --source=560b7f4 -- lib/client.js package.json dsh-plugin.naming.json locale/en.json locale/zh.json README.md README.en.md CHANGELOG.md
```

只对本次改动使用该命令。新增测试、验证文档和开发配置不影响旧客户端运行，可保留。回退后刷新插件信息和客户端。旧 localStorage 配置与收藏键未删除，旧版仍可读取；新版本新增偏好不会反向写入旧键。
